# Network Intrusion Detection using Machine Learning

## Overview
This project builds a real-time Network Intrusion Detection System using CIC-IDS2017 dataset.

## Features
- Data preprocessing & EDA
- Handling class imbalance (SMOTE + Undersampling)
- Multiple ML models comparison
- Real-time intrusion detection simulation
